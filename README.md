# Java Database Connection (Connect-with-JDBC) 🗄️

A backend project focused on establishing database connectivity in Java using JDBC (Java Database Connectivity). This project demonstrates the core concepts of working with relational databases directly through Java code.

## Features
- Established successful connection between Java applications and SQL databases.
- Executed basic database operations (CRUD) using JDBC API.
- Managed database drivers and connection configurations efficiently.

## Tech Stack
- Java Core
- JDBC (Java Database Connectivity)
- SQL / Relational Database
